# Local development notes

The repository's root scripts inject development configuration with Infisical using the project ID, domain, environment, and path recorded in `package.json`. Use those scripts (`pnpm dev`, `pnpm dev:frontend`, `pnpm dev:media`, and related commands) instead of relying on an unqualified Infisical profile.

The frontend `prepare` script runs Convex code generation. A fresh checkout without `CONVEX_DEPLOYMENT` should install the frontend with `--ignore-scripts`, as the root README does, then run code generation only after the Convex environment is configured.

The renderer's virtual environment is ignored at `backend/renderer_service/.venv/`; `pnpm dev:renderer` expects its Uvicorn executable there and starts the app on port 8001.

`frontend/lib/dash/version.ts` is generated by `frontend/scripts/write-version.sh` during typecheck/build and is ignored by Git. Do not add it to a commit.
